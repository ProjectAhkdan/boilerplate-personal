# AI & Data Engineering Interview

## Question Bank: AI Engineer
- **Models**: Model Provider, Selection, Cost, Latency?
- **Integration**: Prompt Architecture, Structured Output, Tool Calling?
- **Infrastructure**: RAG, Embeddings, Vector Database?
- **Quality**: Context window limits, Token Usage, Evaluation, Fallback, Safety?

## Question Bank: Data Engineer & MLOps
- **Pipelines**: ETL/ELT pipelines, Data Warehouse, Streaming vs Batch?
- **Quality**: Data Quality, Monitoring, Lineage?
- **MLOps**: Model Registry, Experiment Tracking, Deployment, Drift Detection, Rollback?
