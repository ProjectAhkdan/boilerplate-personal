# Frontend Engineering Interview & Knowledge

## Adaptive Interview Depth
- **Simple**: High-level UI/Routing.
- **Medium**: State, Components, Data Fetching.
- **Complex**: Architecture, Caching, Rendering Strategies, Performance.

## Question Bank
### Architecture
- Routing strategy? Server vs Client Components?
- Component boundaries? Feature boundaries?
- Rendering Strategy (SSR, SSG, CSR, ISR)?
- Global vs Local State Management? Caching strategy?

### Design System & UX
- Design tokens? Theming?
- UX States (Loading, Empty, Error, Offline, Unauthorized)?
- Responsive design targets (Mobile-first, breakpoints)?

### Performance & Quality
- Core Web Vitals budget? Code splitting/Lazy loading strategy?
- Form validation schema (e.g., Zod) and optimistic updates?
- Testing strategy (Unit, Integration, E2E, Visual, Accessibility)?
