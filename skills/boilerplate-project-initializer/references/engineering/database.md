# Database Engineering Interview & Knowledge

## Question Bank
### Schema & Modeling
- Core Entities and their Relationships?
- Primary/Foreign Key strategies? Indexing for high-read tables?
- Normalization level vs Denormalization for performance?

### Integrity & Security
- Constraints (Unique, Checks) enforced at DB level?
- Row Level Security (RLS) and Policies (especially for Supabase/PostgreSQL)?
- Ownership, Retention, and Soft Delete strategies?

### Operations
- Migration management strategy?
- Transaction boundaries?
- Audit Fields (created_at, updated_at, created_by)?
- Triggers and Database Functions needed?
