# DevOps & Security Engineering Interview

## Question Bank: DevOps
- **Environments**: Development, Preview, Staging, Production setup?
- **CI/CD**: Build, Test, Deploy pipelines? Artifact management?
- **Configuration**: Secrets and Environment Variables management?
- **Operations**: Rollback strategy? Logging and Monitoring infrastructure?
- **Database**: Automated Migration execution strategy?

## Question Bank: Security & DevSecOps
- **Threat Model**: Trust boundaries and attack surfaces?
- **Data Sensitivity**: Handling PII, Compliance needs (GDPR, SOC2)?
- **Mitigation**: XSS, CSRF, SSRF, SQL Injection, CORS policies?
- **Supply Chain**: Dependency security and audit logging?
- **Incident Response**: Strategy for sensitive data breaches?
