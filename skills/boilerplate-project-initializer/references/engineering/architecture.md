# Software Architecture Interview

## Question Bank
- **Architectural Style**: Monolith, Microservices, Serverless, Event-Driven?
- **Boundaries**: Module, Domain, and Dependency boundaries?
- **Data Flow**: Direction of dependencies and data flow? External dependencies?
- **Scalability**: Failure isolation and horizontal vs vertical scaling?
- **Boilerplate Comparison**: Boilerplate Architecture vs Required Project Architecture (KEEP, EXTEND, MODIFY, RESTRUCTURE, REMOVE)?
