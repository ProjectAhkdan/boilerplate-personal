# Backend Engineering Interview & Knowledge

## Adaptive Interview Depth
Scale questions based on project complexity. Focus on API contracts and business logic boundaries.

## Question Bank
### API Architecture
- Architectural Style (REST, GraphQL, RPC, Server Actions)?
- API Versioning strategy?
- Data exchange formats and pagination/filtering/sorting standards?

### Business Logic & Security
- Where does core business logic reside? Validation responsibility?
- Authentication (JWT, Sessions) and Authorization boundaries (RBAC/ABAC)?
- Rate limiting and Idempotency strategies?

### Performance & Scalability
- Caching strategy (Redis, Memcached)?
- Queues and Background Jobs (e.g., BullMQ) for heavy tasks?
- Transaction management and Failure Isolation?

### Observability
- Error Handling contract?
- Logging, Monitoring, and Tracing setup?
